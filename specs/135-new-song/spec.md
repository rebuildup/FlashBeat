# Spec: #135

New-song registration complete in the Web Studio, browser only, for exhibition-booth use. A guided 3-step flow (`/new-song`, 曲情報 → 譜面 → 公開) with a visible stepper: YouTube URL paste with 11-char id validation and oEmbed title/artist fill (offline fallback), duration numeric field plus auto-from-player, songId slug suggestion unique against the live catalog (`このIDは使用済み` + alternatives), level 1–99, bilingual JA/EN field errors. Chart step reuses the eight-lane editor with the video; draft persisted in sessionStorage (reload-safe); minimum-notes rule (≥1 blocks, <20 warns). Publish step: runtime-only staff token (never URL/storage), summary, `publishAndVerify` read-back, verified success view with songId/chartVersion/noteCount and the 「ゲームで見つかるまで」 checklist; failure keeps every input. No deploy, no production API writes; fixture transport for tests and review.

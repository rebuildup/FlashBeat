# Spec: #97

`web/tests/e2e/` に本番 `https://flashbeat.rebuildup.dev` に対する段階別実値検証スクリプト (TypeScript/Node, repo の tooling で実行) を作る。既定は read-only。Stage 1: `GET /api/v1/catalog` で catalogVersion/songs/ids を記録。Stage 2: 曲を選び `GET /api/v1/charts/{id}?version=N` で songId/chartVersion/youtubeId/noteCount == chart.notes.length を catalog 実値と照合。Stage 3: `contracts/schemas/chart.v1.schema.json` でスナップショットを検証。Stage 4 (任意): `--write --song-id <id> --token-env FLASHBEAT_ADMIN_TOKEN` が全て揃った時だけ `PUT /api/v1/admin/songs/{id}` で修正コピーを publish し、再取得で chartVersion+1 / catalogVersion+1 / スナップショット完全一致を検証 (`publishAndVerify` を再利用)。レポートは `{stage, expected, actual, pass}` を stdout と `web/tests/e2e/last-report.json` (gitignored) へ出力。比較ロジックの unit test (vitest, fetch mock) と README を添付。シークレットは読まない・印字しない。Refs #41.

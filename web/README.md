# FlashBeat Web Studio

Standalone web app for the festival build. The Unity project is a separate
application and is never moved by this app.

Void (native routes + pages) · Vite+ · React 19 + TypeScript · Panda CSS · Park UI
(Ark UI) · lucide-react.

## Run it

```sh
vp install     # installs deps, runs `void prepare` + `panda codegen`
vp dev         # http://localhost:5173
vp check       # oxfmt + oxlint
npx tsc --noEmit
vp build
```

`styled-system/` is generated by Panda and gitignored.

### Toolchain versions

Verified with Node 26.13.0, `vite-plus` 1.5.0 (`vp`), `void` 1.6.2, TypeScript 7.0.2,
`@pandacss/*` 2.5.0, `@ark-ui/react` 5.40.0, `@park-ui/cli` 1.0.1, `lucide-react` 1.70.0.

The root `mise.toml` is owned outside this issue, so the versions are pinned in
`package.json` and listed here instead.

## State

There is no backend yet. `src/app/catalog.ts` holds a local fixture that mirrors the
`SongSummary` shape of `contracts/openapi.v1.yaml`. `/?state=loading|empty|error` forces
a list state so every branch can be reviewed before the read endpoint (#15) exists.

See `AGENTS.md` for the layout, the commands and the three manual fixes
`@park-ui/cli@1.0.1` needs for the Panda v2 API.

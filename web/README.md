# FlashBeat Web Studio

Standalone web app for the festival build. The Unity project is a separate
application and is never moved by this app.

Void (native routes + pages) · Vite+ · React 19 + TypeScript · Panda CSS · Park UI
(Ark UI) · lucide-react.

## Run it

```sh
vp install     # installs deps, runs `void prepare` + `panda codegen`
vp dev         # http://localhost:5173
vp check       # oxfmt + oxlint
npx tsc --noEmit
npx vitest run # unit tests
vp build
npm test       # database tests (node --test tests/)
```

### Database

```sh
void db generate   # regenerate db/migrations/ after a schema change
void db migrate    # apply pending migrations to the local D1
void db seed       # reset the local D1, re-apply migrations, run db/seed.ts
void db status     # applied/pending migrations
```

`songs`, `chart_versions` and `scores` follow `contracts/openapi.v1.yaml`; the
contract's limits are SQLite `CHECK` constraints. The migration is applied to the
FlashBeat D1 database with the official `cf` CLI — see
[`docs/operations/d1-migrations.md`](../docs/operations/d1-migrations.md).

`styled-system/` is generated by Panda and gitignored.

### Toolchain versions

`@pandacss/*` 2.5.0, `@ark-ui/react` 5.40.0, `@park-ui/cli` 1.0.1, `lucide-react` 1.70.0.

The root `mise.toml` is owned outside this issue, so the versions are pinned in
`package.json` and listed here instead.

## Chart editor

`/chart` is the eight lane chart editor (issue #18). It reads and writes the legacy
FlashBeat chart JSON, draws the grid with `react-konva` and previews the song with the
YouTube IFrame API. It needs no backend: it opens with a real chart of the Unity
project and can be used before the publish API exists.

![chart editor 1280x720](docs/screenshots/chart-editor-1280x720.png)

## State

There are no API routes yet. The D1 schema and its migration exist (issue #14) but
nothing reads or writes them until #15/#16 add the routes. `src/app/catalog.ts` holds
a local fixture that mirrors the `SongSummary` shape of `contracts/openapi.v1.yaml`.
`/?state=loading|empty|error` forces a list state so every branch can be reviewed
before the read endpoint (#15) exists.

See `AGENTS.md` for the layout, the commands and the three manual fixes
`@park-ui/cli@1.0.1` needs for the Panda v2 API.

## 0. 準備 (1 回だけ)

初回に「開発元を確認できません」と出たら、アプリを**右クリック → 開く**。

## 1. 起動 (10 秒)

1. 上記コマンド、または Finder でアプリをダブルクリック。
2. **全画面でタイトル画面**が出ることを確認 (ウィンドウ枠が無いこと)。

## 2. 選曲 (1 分)

1. `Space` でタイトルから選曲へ。
2. 一覧が **3 カラム** (曲リスト / 曲の詳細 / BEST・ランキング) で出ること。
3. `↓` で数曲動かし、`Tab` で検索欄に入って 2〜3 文字打ち、候補が絞られること。
4. `Esc` で検索をやめ、好きな曲を選んで `Space` (Ready)。

## 3. Game (2 分)

1. ノーツ・レーン・キーガイド・歌詞が出ること。
2. `Space` で再生開始 → 曲に合わせてノーツが落ち、**音と映像が出る**こと。
3. 8 レーン (下段のキー表記) で数回叩き、判定 (`Perfect` 等) とコンボが動くこと。

## 4. Result と Retry (1 分)

1. 曲が終わると Result へ。**スコア・ランク・判定表・Retry / Register / OK** が出ること。
2. `R` で Retry → **同じ曲で Game に戻る**こと (曲が変わらない)。
3. `Esc` などで Result → 選曲へ戻り、**別の曲**を選んで開始できること。
4. (任意) `T` でタイトルへ戻れること。

## 5. 終了

`Cmd+Q` で終了 (全画面のまま)。

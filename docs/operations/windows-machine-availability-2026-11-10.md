## 1. 前回の報告の訂正

前回「Mac から展示 PC への remote 経路は文書化されていない (Herdr はローカル専用)」と
報告したが、**これは誤り**。実際には Herdr に Windows 機が登録されており、SSH で到達できる。

| 項目 | 実測値 |
|---|---|
| `herdr machine list` | ラベル **Windows** (`target: device-windows`, session `default`, enabled) と **Ubuntu (WSL)** (`device-wsl`) |
| `herdr machine status Windows` | **`reachable`** (error なし) |
| SSH 定義 | `~/.ssh/devices.conf` の `Host device-windows` → `100.118.123.62:22222` / user `basic` / `id_ed25519_devices` (Tailscale 網) |
| 到達性 | `nc -z 100.118.123.62 22222` → **open** |
| SSH ログイン | 成功。リモートの既定シェルは **cmd.exe** (Unix 風の `hostname` は Git for Windows のものが先に当たる) |

つまり **「接続できるか」の答えは「できる」**。前回の「経路が無い」は撤回する。

**前回のこの文書 (初版) は「この Windows 機は展示 PC ではなく常用の開発機である」と断定した。
これは撤回する。** 断定できる根拠が無く、逆に「展示 PC である」ことを示す材料がある。

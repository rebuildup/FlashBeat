- リモート参照の削除は `git push origin` の削除オプションでしか行えず、このリポジトリの
  破壊的ガードがそれを禁止している。**ガードを迂回しない**方針のため、本表は「削除してよいと
  証明できる候補」の記録に留める。
- 実施する場合は、上表のブランチが **すべて `origin/main` の祖先**であることを再確認したうえで、

  open PR の head (現在 0 件)、ローカル branch と worktree がチェックアウトしているブランチ。
- 証拠の再生成: `git branch -r --merged origin/main` と `git worktree list` を突き合わせる。

## 2. HUD: 上部シェードと歌詞 (#379)

### 2.1 上部シェード

上部シェードは **削除しない**。動画の明るい場面でも HUD の白文字を読めるようにするための面であり、オーナー指摘の実体は「一様な黒帯の下端が見えること」である。上端の不透明度と高さは維持し、下端だけを透明にする。

- 塗り: 線形グラデーション、回転 180° (上 → 下)、`#000000A6` (位置 0) → `#00000000` (位置 1)。
- 高さ: FHD 260 / 2K 347 / Mac 347。これは design の初期値であり、実機で文字の可読性を確認してから調整してよい。高さを変える場合も上端の色は変えない。
- グラデーションの終端が画面の暗部と一致するため、帯の境界線は見えない。

### 2.2 歌詞の位置

歌詞枠は design `i30vM4` (ゲームフレーム 1728×972 の (304,250)、1120×220) を実画面へ写す。写像はプレイフィールドと同じ **高さ合わせ + 水平中央寄せ** を使う。

```
scale = 画面高さ / 972
幅   = 1120 × scale
高さ = 220 × scale
x    = 画面中央 (design の中心 864 を画面中心へ)
y    = 250 × scale
```

したがって FHD (1920×1080) では y=278、2K (2560×1440) では y=370、Mac (2560×1664) では y=428 が枠の上端になる。実装の固定値 (170 / 227 / 227) は廃止する。歌詞枠の内部 (Furigana 22 / Lyrics 44 / Romaji 20、gap 6、padding 24/16) は design のまま。

### 2.3 スコアと判定

- スコア値は 1 行固定。折り返しを禁止し、幅を超える場合はフォントサイズを自動で下げる (下限 28px、design の 38px から)。7 桁・8 桁でも 1 行に収まることをテストで固定する。
- 加算時は値の変化に合わせて 1.0 → 1.06 → 1.0 のスケールポップを付ける (80ms + 120ms)。ポップは表示だけで、レイアウトを動かさない。
- 判定行は v6 の行 (`V6UiMode.VerdictRow = true`) を有効化し、レーン中心に design のサイズ (FHD 30 / 2K・Mac 40) で表示する。旧 HUD の判定表示と二重に出さない。

## 3. 音量スライダー (#375)

音量は数値の増減ボタンだけでなく、**連続的に動かせるスライダー** で調整する。Option の Sound タブと Pause の Sound タブは同じ部品を使う。

### 3.1 部品

`Components v6` (`o0zh7`) に `Volume Slider` を置く。構成は値ラベル、トラック、フィル、ノブ、操作ヒント。

| 部位 | 寸法 | 色 |
|---|---|---|
| 値ラベル | 幅 464、フォント 58 | `$text` |
| トラック | 464×20、角丸 10 | `$k1` |
| フィル | 値の割合 × 464、高さ 20 | `$k6` |
| ノブ | 24×24、角丸 12 | `$text` |
| 操作ヒント | フォント 18 | `$text-dim` |

ノブの中心 x は `24 + 440 × value`。トラックの左端から右端までが 0〜100% に対応する。

### 3.2 操作

- トラック上のドラッグ: ポインタ位置を値へ写す。押した瞬間にその位置へジャンプし、そのままドラッグで連続変化する。
- キーボード: 左右キーで 1% ずつ、Shift + 左右で 10% ずつ。フォーカス行の値とスライダーは常に同期する。
- 値の範囲は既存の 0〜1 (`GManager.mainVolume` / `effectVolume` / `BGMVolume`)。表示は 0〜100%。
- 変更は即時に音へ反映する。保存はドラッグ終了時とキー操作の 0.5 秒後にまとめて行い、ドラッグ中に毎フレーム書き込まない。
- 設定行の左右矢印は残す (#370 の整列規則)。矢印とスライダーは同じ値を編集する。

## 4. キー設定モーダル (#376)

### 4.1 入口と F2 の扱い

Option の Play タブと Pause の Play タブにある「キー設定」行から開く。行の値は `開く ›` とし、`F2` は表示しない。`F2` の入力監視は削除する。キー設定への到達経路は画面内の行だけにする。

### 4.2 画面

Modal 契約 (scrim 1728×972 `#00000099`、ダイアログ 840×724 `$k1` r16) に従う。

| 部位 | xy | wh | 内容 |
|---|---|---|---|
| 見出し | (28,28) | 784×40 | 「キー設定」fs32 w700 |
| 説明 | (28,72) | 784×24 | 「レーンごとに代表キーを変更します。」fs22 `$text-dim` |
| レーン一覧 | (28,112) | 784×472 | 8 行、行高 52、行間 8 |
| フッター | (28,612) | 784×56 | 既定に戻す 220×56 / キャンセル 180×56 / 適用 252×56 |

各行は `$k2` r8。左からレーン名 (幅 120、fs22 `$text-dim`)、代表キーの KeyCap (120×40、fs24)、状態テキスト (残り幅、fs20 `$text-muted`)。状態テキストは通常「変更」、選択中は「Enter で変更」、待受中は「キーを押してください」、衝突時は「Lane N で使用中」(`$danger-light`)。

代表キーの下 (行内 2 行目) に、そのレーンの残りのキーを `Q / W / A / Z` の形で fs16 `$text-muted` で表示する。既定では 1 レーンに複数のキーが割り当てられているため、代表キーを変えても残りは保持する。

### 4.3 状態と操作

```
Closed → Editing (行選択)
Editing → Listening (Enter / クリック)
Listening → Editing (キー確定 / Esc で中止)
Editing → Closed (Esc / キャンセル: 破棄)
Editing → Applied (適用: 保存して閉じる)
```

- ↑↓ と ←→ で行を移動する。Enter または行のクリックで待受に入る。マウスでも行を選べる。
- 待受中は Esc 以外のキーを 1 つ受け取り、そのキーを代表キーに割り当てる。Esc は待受を中止して Editing に戻る。
- 同じキーが他のレーンの代表キーまたは残りキーに含まれる場合は確定しない。衝突先のレーン番号を表示し、待受を続ける。
- 「既定に戻す」は編集内容を既定表 (`KeyBindings.DefaultKeys`) に戻す。保存は「適用」まで行わない。
- 「適用」で全レーンを保存し、ゲーム内の判定とキーガイドへ即時反映する。「キャンセル」と Esc は編集内容を破棄する。
- モーダル表示中は背後の画面へキー入力を渡さない。名前入力と同様、Esc だけをモーダルが消費する。

## 5. 再開カウントダウン (#382)

### 5.1 状態

```
Playing → Paused (Esc)
Paused → CountingDown (再開)
CountingDown → Paused (Esc: キャンセル)
CountingDown → Playing (3 秒経過)
```

カウントダウンは 3.0 秒。表示は 0〜1 秒が `3`、1〜2 秒が `2`、2〜3 秒が `1`。3 秒経過と同時に判定基準時刻を再同期し、音声・映像・譜面を再開する。

### 5.2 表示

- 位置は歌詞スロット (§2.2) と同じ。歌詞と Start Prompt はカウントダウン中だけ隠す。
- 数字は中央揃え、fs132 (design 1728×972 基準)、w700、`$text`。
- カウントダウン中は判定キーを受け付けない。ノート・判定エフェクト・レーンのフラッシュも静止させる。
- Esc で Paused に戻ったときは、数字を消して歌詞を戻し、再度再開できる状態にする。

## 6. 曲終了と譜面パラメータ (#383)

### 6.1 譜面スキーマ

`Assets/Game/Resources/<song>.json` のトップレベルに次の任意フィールドを追加する。既存譜面は変更なしで読める。

| フィールド | 型 | 既定値 | 意味 |
|---|---|---|---|
| `fadeOut` | float 秒 | 2.0 | メディア終端の何秒前からフェードを始めるか |
| `startTiming` | float 秒 | 0.0 | プレイヤーが開始した後、音声と譜面を始めるまでの待ち時間 |
| `beatOffset` | float 秒 | 0.0 | BPM グリッドと音源のずれ補正。全ノート時刻に加算する |

`offset` は NoteEditor が書き出すサンプル単位の音声アラインメント値であり、**実行時の判定には使わない**。実行時の拍補正は `beatOffset` に一本化する。この役割分担をコメントとテストで固定し、`offset` を拍補正と誤解しないようにする。

`beatOffset` の適用式:

```
ノート時刻 = NoteTimeSeconds(BPM, note) + beatOffset + noteTiming × 0.01
```

正の値はノートを遅らせる。`fadeOut` は 0〜10 秒かつメディア長の 25% 以下にクランプする。`startTiming` は 0〜10 秒、`beatOffset` は −2〜2 秒にクランプし、範囲外は既定値へ戻して警告を出す。

### 6.2 終了の見せ方

- フェードは音声と映像の両方にかける。音声は音量を線形に下げ、映像は全画面の黒オーバーレイを不透明へ近づける。映像そのものの再生は止めない。
- フェード開始と同時に歌詞スロットへ「終了」を表示する (`Song End Overlay`)。歌詞と Start Prompt は隠す。
- Result へはメディア終端から 0.8 秒後に遷移する。メディア長が取得できない場合は、最終ノート時刻 + `fadeOut` + 0.8 秒を終端とみなす。
- フェード中と終了表示中は判定キーを受け付けない。総ノーツ数と判定数の合計は変えない (#226 の回帰を壊さない)。
- `startTiming` が 0 より大きい場合、開始入力後に歌詞スロットへ「START」を表示し、待ち時間の経過後に音声と譜面を同時に始める。待ち時間中は判定キーを受け付けない。

### 6.3 NoteEditor との往復

`EditDataSerializer` の読み書きと YouTube 取り込み経路で 3 フィールドを保持する。NoteEditor の既存 `offset` (サンプル) とは別フィールドとして扱い、相互に変換しない。

## 7. Result: 段階表示と登録 (#384)

### 7.1 タイムライン

Result を開いた時点を 0ms とする。すべての段階はスキップ可能で、最終状態では全要素が表示されている。

| 開始 | 要素 | 動き |
|---|---|---|
| 0 | トロフィー | 0.6 → 1.0 のスケール + フェードイン 180ms (ease-out) |
| 120 | グレード文字 | 0.9 → 1.0 + フェードイン 180ms |
| 300 | スコアラベル | フェードイン 120ms |
| 300 | スコア値 | 0 から最終値へ 900ms でカウントアップ (ease-out) |
| 1250 | 前回最高 | フェードイン 180ms |
| 1400 | 判定内訳 5 列 | 60ms 間隔でフェードイン |
| 1450 | スコアゲージ | 最終値まで 500ms |
| 1750 | 曲情報・ランキング | フェードイン 200ms |
| 2000 | 登録欄 | フェードイン 180ms。名前欄にフォーカス |

### 7.2 Space スキップ

段階表示中に Space を押すと、実行中の演出を止め、すべての要素を最終状態で表示する。スキップ後もスコア・判定・登録欄はすべて見えており、以降は通常操作になる。スキップは 1 回だけ作用し、登録の送信を開始しない。

### 7.3 名前入力

- 入力欄はフォーカス中に 2×44 の点滅カーソルを表示する。点滅周期は 530ms。
- 最大 8 文字。Enter またはフォーカス喪失で確定する。
- 確定時に名前が空でなければ自動で登録する。登録ボタンは残すが、押さなくても登録される。
- 日本語 (IME) の入力を許可する。入力欄がフォーカス中は、Esc 以外のキーを画面のショートカットへ渡さない。
- 登録は Idle → Submitting → Succeeded / Failed の状態を持つ。Submitting 中の Enter・フォーカス喪失・再入力では再送しない。Succeeded 後も再送しない。Failed のときだけ「再試行」を出す。
- 成功時はダイアログ右上に「登録しました」のチップ (`$ok-tint` 背景、`$ok-light` 文字) を 180ms で出し、2 秒保持して 300ms で消す。失敗時は「登録できませんでした」(`$danger-tint` / `$danger-light`) と再試行を出す。
- オンライン登録の確認はテスト環境に対して行う。本番 API への無承認書き込みはしない。

## 8. 検証と証拠の分離

| 項目 | Mac 実機 | Win64 CI |

## 9. 実機で決める残余

- 上部シェードの高さ 260 / 347 は初期値。実機で歌詞とスコアの可読性を見てから調整する。調整しても上端の色 `#000000A6` は変えない。
- カウントダウンの数字サイズ 132 は design 基準。実機で大きすぎる / 小さすぎる場合だけ変更する。
- 登録成功チップの保持時間 2 秒は目安。実機のテンポを見て調整してよい。

## 10. 2026-11-12 オーナー再レビューの決定

前節までの実装を見たオーナーの指摘と、その決定。実装はこの節を正とする。

### 10.1 Result のトロフィー位置

**トロフィーはメイン領域ではなく、ヘッダー左上の空きスロットに置く。**

- 他画面 (Title / Select / History / Ranking / Option) の左上は戻るボタン (56×56) で、
  Result だけ同じ位置が空白になっていた。ここが「空白ができている」の実体。
- Result の戻るはフッターの OK / Esc が担うため、左上は結果の記号に使える。
- 置き方: 他画面の戻るボタンと同じ 56×56 `$k4` r8 のバッジに、trophy アイコン 28px を
  中央配置。メイン領域の (337,1) 30×30 は廃止する。
- 段階表示のスケール演出はこのバッジに掛ける (メイン領域の要素ではない)。

### 10.2 Option のキー一覧

**キーキャップに出すのはキー名で、レーン番号ではない。**

- 以前は `DisplayLaneOf` の結果 (レーン番号) を出していたため、同じレーンに属する
  キーが同じ数字になり「1 2 3 4 4 5 5 6 7 8 8 8」のような崩れた表示になっていた。
- レーン番号は Game Preview 側のレーンラベルが担う。キー一覧は「どのキーがあるか」を
  示す場所なので、キー名を出す。
- 説明文の「F2 でも開けます」は廃止済みの導線なので削除する。

### 10.3 判定の出現

**判定は判定線から立ち上がる。**

- 「正しく叩いた感覚」を判定線の位置で返すため、判定テキストは判定線のすぐ上に出て、
  140ms で所定位置まで立ち上がる (28px、EaseOut)。
- 寿命の最後 220ms でフェードアウトする。出現は即時 (フェードインしない)。
- レイアウトは動かさない (anchoredPosition の y だけを時間で変える)。

### 10.4 コンボのポップ

**コンボもスコアと同じ時間割でポップする。**

- スコアは加算で 1→1.06→1 に拡大するのに、コンボだけ静止していて手応えが
  片方にしか出ていなかった。
- 倍率・時間 (`V6HudLogic.ScorePulseScale`) を共有し、レイアウトは動かさない。
- 減少 (ミス) ではポップさせない (増加のときだけ)。

### 10.5 歌詞スロット

**歌詞パネルは文字に合わせた大きさにする。通常 UI 側の要素として扱う。**

- design の 220×scale をそのまま使うと、フォントが画面倍率に追従しない分だけ
  「大きな空の板」になる (Mac では文字が箱の 1 割)。高さは行構成から求める。
- 3 行 (振り仮名 / 歌詞 / ローマ字) は常に確保する。行が空でも高さを変えない
  (行数が変わって箱が伸縮するのを避ける)。
- テキストの強弱は design の 3 段 (22 / 44 / 20) を維持し、極端な大小を付けない。
- カウントダウンと START は同じスロットを使うが、START は数字より小さい
  見出しサイズ (design 64) にして体裁を揃える。

### 10.6 Result の段階表示

**毎回変わらない要素はアニメーションしない。**

- 楽曲情報とランキングは最初から表示する (SongInfoStart = 0)。
- 段階表示するのは「毎回変わる」要素だけ: トロフィー / グレード / スコア /
  判定内訳 / スコアゲージ。
- 期待感はこの 5 要素で作る。曲情報とランキングを待たせても期待は生まれない。

### 10.7 ボタンの押下フィードバック

**押したら輪郭が外へ広がって消える (地味なマイクロアニメーション)。**

- 120ms、1.0→1.12 倍、不透明度 0.28→0。ボタンの後ろで輪郭だけが広がる。
- 色の反転・ボタン自体の拡大・文字の移動はしない (派手にしない)。
- `V6Controls` の Button / BackButton から生成する全ボタンに同じように付ける。

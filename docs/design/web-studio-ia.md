# Web Studio 情報設計（IA）仕様 — issue #742

対象: `web/` の運営者向け画面。利用者の目的は「曲を探す / 新規登録 / 編集 /
公開 / ランキング確認」の5系統。この文書は各画面の primary / secondary /
tertiary action と、その根拠を固定する。視覚 token や文言の正本は
`web/AGENTS.md` と Panda/Park UI 側にあり、ここでは**情報の優先度と導線**だけを
扱う。

## 導線の全体像

```
訪問者:  / (曲を選ぶ) ──行リンク──> /chart?songId=… (譜面を見て試す)
スタッフ: /new-song (登録ガイド) ──> /chart (編集) ──draft──> /publish (公開)
          /dashboard (確認)   /songs (アーカイブ/復元)
```

- `/new-song` は3ステップのガイド付きフローで、登録の**推奨経路**。
- `/chart`・`/publish` は単体画面の**上級者経路**。どちらも下書き
  (`sessionStorage`) で往復でき、編集内容は失われない。
- 公開にはスタッフの admin トークンが必要。境界はクリック**前**に各所へ
  表示する（サイドバーの「要トークン」バッジ、ページ内のヒント）。

## ナビゲーション（`src/app/sidebar.tsx`）

訪問者エントリ「曲を選ぶ」を先頭に、スタッフ項目を作業単位で2群に分ける。

| 群 | 順 | 項目 | 役割 |
| --- | --- | --- | --- |
| 制作 | 1 | 新曲を登録 `/new-song` | 登録の入口（ガイド付き） |
| 制作 | 2 | 譜面を編集 `/chart` | 譜面の作成・確認・試聴 |
| 制作 | 3 | 公開する `/publish` | 公開操作（要トークン） |
| 運営 | 4 | ダッシュボード `/dashboard` | スコア・統計の確認 |
| 運営 | 5 | 楽曲アーカイブ `/songs` | アーカイブ / 復元 |

- 「制作」を先に置くのは、スタッフの最頻出の目的が制作だから。監視系
  （ダッシュボード・アーカイブ）は「運営」に下げる。
- 群ラベル（制作 / 運営）は全ビューポートで表示する。狭い画面の2列
  グリッドでは全幅の行として群の切れ目を示す。
- ラベル・ルート・`data-testid`・admin バッジは変更しない。順序と群分け
  だけの変更であり、E2E のセレクタはそのまま有効。

## 画面別の action 階層

### `/` 曲を選ぶ（訪問者 + スタッフ共用）

- **Primary**: ヒーローの「リストから曲を選ぶ」（先頭行 or 検索へ誘導）。
- **Secondary**: 行リンク → `/chart?songId=…`（その譜面を開いて試す）。
- **Filters**: 検索・レベル・並び替えは一覧の直上のトップバーに集約。
- 状態（loading / empty / error / offline）は同じ枠で表示し、遷移で
  レイアウトが跳ねない。

### `/new-song` 新曲を登録

- **Primary**: 各ステップの「次へ」（最終ステップは公開）。
- **Secondary**: 「戻る」（下書きは sessionStorage に残る）。
- ヘッダに目的と権限境界（admin トークン要）を最初に明示する。

### `/chart` 譜面を編集

- **Primary（選択曲あり）**: 「再生して試す」— プレビューを表示して
  フォーカスする。訪問者の主目的は試聴。
- **Secondary**: 「公開に進む」（下書きを保存して `/publish` へ）、
  YouTube 外部リンク。
- 権限境界（admin トークン要）は secondary の隣に常時表示。
- 未選択（新規下書き）では公開導線のみが主操作。

### `/publish` 曲を公開

- **Primary**: 公開ダイアログの確定（トークン入力が前提）。
- **Secondary**: エディタへ戻る下書きリンク、メタデータ編集。
- loading / error は同じカード枠で「再試行」「← 曲を選ぶ」を出す。

### `/dashboard` ダッシュボード

- **Primary 情報**: 6タイル（公開中の曲・アーカイブ・譜面・プレイ・
  プレイヤー・24hプレイ）→ ランキング → 曲の詳細 → 上位プレイヤー →
  難易度分布の順。左列（広い）にランキングと曲詳細、右列に補助情報。
- action は持たない読み取り専用画面。error は「再試行」のみ。

### `/songs` 楽曲アーカイブ

- **Primary**: トークン入力 → 「曲を一覧する」で一覧を開く。
- **Row action**: アーカイブ / 復元（破壊的でないソフト削除。曲・譜面・
  スコア・ランキングは保持されることを画面上部で説明）。
- 誤操作の回復: 復元は同じ一覧から即座に可能。

## 一貫性のルール

- 1画面に solid の primary CTA は1つ。公開系は常に outline + 権限ヒント。
- エラーは原因と次の行動（再試行 / 戻る）を必ず書く。
- 空・読込・失敗は同じ枠（`panelFrame` / `stateBlock`）で高さを保つ。
- ナビの現ページは `aria-current="page"`、キーボード操作・フォーカス輪郭は
  既存の `_focusVisible` トークンに従う。

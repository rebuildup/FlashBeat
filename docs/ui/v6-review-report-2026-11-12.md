## 1. 判断が必要なこと

### D-1: macOS でメニューバー 76 px が被覆されないまま、展示で許容するか

Unity の macOS プレイヤーが FullScreenWindow でも NSScreen.visibleFrame サイズのウィンドウを作るため、アプリコードだけでは解消できません。ネイティブバンドルでの回避は試作時点でクラッシュし、成果物に含めていません。Win64 では別の挙動になる可能性があり、実機確認が先です。

### D-2: キー設定の衝突・リセット操作を実機で確認するか、EditMode の範囲で足りるとするか

衝突検出と既定復帰は EditMode で固定済みですが、実機のキー入力では未確認です。展示でキー設定を触る運用にするなら実機確認が必要です。

### D-3: History / Ranking の右上ジャケットを Issue 記載の 300×96 に戻すか、現行 pen の 64×36 を正とするか

Issue には「ジャケットが小さい (300×96 のはず)」とありますが、現行 pen (S1TZD) は 64×36 です。pen を正としたため是正していません。どちらが意図かはオーナー判断です。

### D-4: 凍結候補 b6860a80 を維持するか、今回の修正 (PR #387) を含むビルドへ差し替えるか

PR #387 で未解決レビュー指摘 8 件 (開始待ちの無限ループ・曲終端が 1 秒早い・判定前の暗転・キー保存失敗時の不整合など) を修正し main へ統合しました。凍結候補 b6860a80 はその前のビルドなので、これらの修正を含みません。差し替えると実機再受入が必要になります。
